# AI Research Assistant

Intelligent Research Paper Analysis and Question Answering System.

## Setup

### Backend

```bash
cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp ../.env .env  # edit with your API keys
python app.py
```

### Frontend

```bash
cd frontend
npm install
npm start
```
